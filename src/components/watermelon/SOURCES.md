# Watermelon UI source

The components in this directory are copied from the MIT-licensed Watermelon UI platform's `src/components/base-ui` directory.

- Source repository — https://github.com/WatermelonCorp/watermelon-platform
- Catalog — https://ui.watermelon.sh/components
- Patterns used — the form-card structure from https://registry.watermelon.sh/r/card-1.json and the action-button composition from https://registry.watermelon.sh/r/button-1.json

Local adaptations normalize state selectors to Radix `data-state` attributes and apply the brand theme through `workbench.css`. The original MIT notice is included in `LICENSE`.
